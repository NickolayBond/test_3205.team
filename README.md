# test_3205.team

## Описание проекта
Сервис асинхронной проверки списка URL. Проект представляет собой полноценное веб-приложение, разделенное на клиентскую и серверную части, предназначенное для быстрой и отказоустойчивой верификации доступности веб-ресурсов.

## Решаемые задачи
* Асинхронный параллельный опрос переданного массива веб-адресов.
* Ограничение конкурентных запросов для предотвращения сетевой перегрузки.
* Передача статусов проверки в реальном времени посредством WebSockets.
* Хранение результатов проверок (in-memory архитектура по умолчанию).
* Предоставление пользовательского интерфейса для мониторинга и инициации проверок.

## Требования к окружению
* Node.js (версия 18 или выше для запуска локальных скриптов автоматизации).
* Docker и Docker Compose.

## Инструкция по запуску

Перед запуском установите зависимости в корневой директории для работы кроссплатформенных скриптов:
```bash
npm install
```

### Разработка (Development)
Запуск контейнеров в интерактивном режиме с поддержкой Hot Reload (изменения в коде мгновенно применяются в контейнерах):
```bash
npm run docker:dev
```
* Backend доступен по адресу: http://localhost:3000
* Frontend доступен по адресу: http://localhost:5173

### Продакшн (Production)
Сборка оптимизированных артефактов и запуск в фоновом режиме. Backend компилируется в JavaScript, Frontend разворачивается под управлением веб-сервера Nginx:
```bash
npm run docker:prod
```
* Backend доступен по адресу: http://localhost:3000
* Frontend доступен по адресу: http://localhost:80

### Очистка окружения
Полная остановка контейнеров, удаление связанных volumes, очистка образов проекта и неиспользуемого кэша Docker:
```bash
npm run docker:clean
```
